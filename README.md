# engenharia-de-software-atividade-avaliativa

Sistema de pedidos da atividade avaliativa de Engenharia de Software, usando Singleton, Builder,
Factory Method e Abstract Factory.

Pra rodar o exemplo completo da integração:

    python main.py

Pra rodar os testes (precisa do pytest, que está no requirements.txt):

    python -m pytest

Os dois comandos têm que ser rodados da raiz do projeto, senão os imports de `src` não resolvem.
O código fica em `src`, os testes em `tests` (um arquivo por questão) e as respostas escritas em
`docs/respostas.md`.
